Errors for a mistyped decision ID name both ID forms and, when the ID is spelled another way (`DL-5`, an upper-case timestamp ID), the canonical spelling to use. The skills no longer describe a set of new decisions as an ID range, skip reserved `<id>--<text>.md` files when reading records, and explain that a snapshot's `modified_decisions` can list a timestamp-ID record it does not cover yet.
