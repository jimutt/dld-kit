## Context

Missing relationships are cheapest to fix when a decision is written: the author knows whether it changes an older decision. `/dld-decide` and `/dld-plan` already ask whether a new decision supersedes or amends the related decisions they found, but nothing checks the body they then write against the flags they pass to `create-decision`. A body that says "Amends DL-031" with no `--amends DL-031` leaves the record contradicting itself until an audit finds it. DL-082 defines the `explicit` and `cue` tiers that can catch this.

## Decision

- `create-decision` reads the body with DL-082's `explicit` rule. For each ID the body says it amends or supersedes that neither `--amends` nor `--supersedes` lists (other than the record's own ID), it warns through `Context.warn` (DL-079): `DL-NNN: the body says it amends DL-XXX, but --amends does not list it` (or `supersedes` and `--supersedes`). The record is still created and the exit code is unchanged.
- After creating their records, `/dld-decide` and `/dld-plan` run `find-missing-amends` with the new IDs.
  - For an `explicit` candidate, they add the ID to the new record's frontmatter (it is a draft), or reword the sentence if it does not describe a real relationship. A new `supersedes` entry also marks the old decision `superseded`.
  - For a `cue` candidate, they ask the user with `AskUserQuestion` whether the new decision amends, supersedes or only cites the referenced one, and update the frontmatter to match.

## Rationale

- The warning is in the command so every caller gets it, not only the skills. It is a warning rather than an error because the `explicit` rule can misread a sentence, such as a negated one ("this never supersedes DL-005"), and an error would leave no way to create that record.
- Running the narrow check while the author is still in the conversation turns the cue tier into one quick question per hit, instead of an audit finding months later.

## Consequences

- Writing a decision can take one more question when its body uses change words near another decision's ID.
- Relationships the body never states still depend on the question the skills already ask before writing.
