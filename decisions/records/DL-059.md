## Context

The `1.0.0-rc.2` release run warned that `actions/download-artifact` and `actions/setup-node` at v4 target Node 20, which GitHub deprecated on its runners in September 2025; they are forced to run on Node 24. Both workflows use v4 pins: `test.yml` by tag, and `release.yml` by commit SHA (DL-052).

## Decision

- Every action in `.github/workflows/test.yml` and `release.yml` moves to its current major version that runs on Node 24:
  - `actions/checkout`
  - `actions/setup-node`
  - `actions/upload-artifact`
  - `actions/download-artifact`
  - `actions/github-script`
  - `oven-sh/setup-bun`, if its current release targets Node 24
- Each action is pinned by full commit SHA, with the version in a trailing comment. `test.yml` moves from tag pins to SHA pins as well.
- The implementation checks each new major's breaking changes against how the workflows use it, for example the artifact v4→v5 download path behaviour. It confirms a green CI run and a dry run of the release jobs' shape (actionlint) before merging.

## Rationale

- Staying on deprecated runtimes risks the workflows breaking when GitHub removes the Node 20 shim.
- SHA pins everywhere keep a moved tag from changing what CI runs.

## Consequences

- SHA pins need deliberate bumps. Dependabot or Renovate for actions can be added later.
- Amends DL-005 (CI uses SHA-pinned actions).
