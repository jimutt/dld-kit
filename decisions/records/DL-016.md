## Context

`create-decision --body-stdin` reads the record body from standard input, and `create-decision` stamps records with the current UTC time. DL-007 keeps `process` out of core, and DL-008 routes everything external through `Context`. PRACTICES.md lists the clock among the things to inject.

## Decision

- `Context` gains `readStdin(): string`. It returns all of standard input as UTF-8 and is called only by commands that were asked to read it. The real implementation reads file descriptor 0 synchronously.
- `Context` gains `now(): Date`. Timestamps are formatted as `YYYY-MM-DDTHH:MM:SSZ` (UTC, no milliseconds), matching `date -u +"%Y-%m-%dT%H:%M:%SZ"` in the scripts.
- Tests pass a fixed string and a fixed date.

## Rationale

- Reading stdin only when asked avoids blocking on an interactive terminal for commands that don't use it.
- An injected clock makes record output deterministic in unit tests, so tests can compare whole files.

## Consequences

- Reading stdin synchronously ties the process to that call until input ends. That matches the script, which runs `cat`.
