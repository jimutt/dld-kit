## Context

`update-audit-state.sh` and `update-snapshot-state.sh` both rewrite `decisions/.dld-state.yaml`, each replacing its own top-level section (`audit:` or `snapshot:`) line by line and keeping the rest. `find-missing-amends.sh` and `detect-snapshot-changes.sh` read fields back with `awk` and `sed`. Skills (`/dld-status`, `/dld-audit`, `/dld-audit-auto`) read the file directly. It stores short commit hashes, and a hash such as `0123456` is all digits: a YAML parser with the default schema reads it as the number 123456.

## Decision

- Core reads `.dld-state.yaml` with the `yaml` package's Document API using the **failsafe** schema, so every scalar is a string and commit hashes survive intact. A missing file is an empty state. A file that is not valid YAML, holds more than one YAML document, or is not a mapping fails with an error naming it, so an update can never drop content it could not read.
- Updates replace a single top-level section (`audit` or `snapshot`) in the parsed document and leave every other section, and comments outside the replaced section, in place. The document is serialised back and written with `writeFileAtomic` (DL-015).
- Section layout and field names stay as the scripts write them:
  - `audit: {last_run, commit_hash}`
  - `snapshot: {last_run, commit_hash, decisions_included, artifacts: {<name>: <timestamp>}}`
  Timestamps come from `Context.now()` in the DL-016 format. `commit_hash` is `git rev-parse --short HEAD`, or `unknown` when HEAD does not resolve.
- Readers take values as strings and convert them where needed: `decisions_included` is a decimal number, and `unknown` or empty means "no commit".

## Rationale

- The failsafe schema is the only way to parse the file without losing leading zeros in hashes, and it matches how the scripts treated every value as text.
- Editing the parsed document per section keeps other tools' sections (and future ones) intact, without the fragile indentation-based line skipping the scripts used.

## Consequences

- Serialisation is the `yaml` package's, so spacing in a hand-edited file may be normalised when a section is updated. Field names, nesting and values are unchanged, which is what the skills and bats tests read.
