## Context

DL-033 stamps every generated SKILL.md with `<!-- Generated by dld-kit from templates/skills/<skill>/SKILL.md. Do not edit; edit the template and run npm run generate. -->`. That is right in this repository, but the committed `skills/` output is what `npx skills` installs into user projects, and `dld init`/`dld update` (DL-040) will write the same stamp there, where there is no template and no `npm run generate`.

## Decision

- The generated-file notice in every output reads: `<!-- Generated by dld-kit from templates/skills/<skill>/SKILL.md. Do not edit: updating the skills overwrites this file. -->`
- Rule files that dld-kit owns (DL-045) carry the same kind of notice, naming `templates/rules/dld-workflow.md`.
- Contributors keep learning where to edit from CLAUDE.md and PRACTICES.md, which already say to edit `templates/` and run `npm run generate`.

## Rationale

- One notice that is true in every place the file lands is simpler than per-channel wording, and a generated file cannot know which channel installed it.
- Keeping the template path helps contributors and costs users nothing.

## Consequences

- Amends DL-033's notice text. Every generated SKILL.md changes by one line.
