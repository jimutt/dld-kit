## Context

Log output was inconsistent — some modules used console.log, others used a custom logger, and production logs were hard to parse for monitoring tools.

## Decision

Adopt a structured JSON logging approach with standardized log levels (debug, info, warn, error). All log output must go through a single logger instance.

## Rationale

Structured logs are machine-parseable and integrate cleanly with log aggregation tools. Consistent log levels make it easy to filter noise in production.

## Consequences

All existing console.log calls must be migrated. Log verbosity is controllable via environment variable.
