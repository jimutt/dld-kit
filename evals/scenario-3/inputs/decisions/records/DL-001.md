## Context

The project needed an HTTP API framework for exposing service endpoints. Options considered included Flask, Django REST Framework, and FastAPI.

## Decision

Use FastAPI as the HTTP API layer. All endpoints are defined in `src/api.py`.

## Rationale

FastAPI provides automatic OpenAPI documentation, native async support, and fast request handling via Starlette. Type hints double as request validation, reducing boilerplate.

## Consequences

- All new endpoints must be added to `src/api.py` and follow the FastAPI routing conventions.
- Async handlers are preferred over synchronous ones.
