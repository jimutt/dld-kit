## Context

During migration from the previous system, a compatibility shim was needed to bridge old client integrations while new endpoints were built out.

## Decision

Maintain a compatibility shim in `src/old_module.py` that translates legacy request formats into the new API contract.

## Rationale

Clients were slow to upgrade; the shim bought migration time without breaking existing integrations.

## Consequences

- `src/old_module.py` must be maintained alongside the main API.
- Once all clients have migrated, this file can be removed and this decision superseded.
