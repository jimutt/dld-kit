# Application Logging Configuration

## Context

The application currently uses ad-hoc `print()` statements and inconsistent logging levels. We need a centralized logging setup that can be imported once at startup and shared across all modules.

## Decision

Implement a `configure_logging(level: str = "INFO") -> logging.Logger` function in `src/logging_config.py` that:

- Creates a logger named `"app"`
- Attaches a `StreamHandler` (stdout)
- Uses the format: `"%(asctime)s [%(levelname)s] %(name)s: %(message)s"`
- Accepts a `level` string parameter (`"DEBUG"`, `"INFO"`, `"WARNING"`, `"ERROR"`) and sets it on the logger
- Returns the configured logger

Only the standard library `logging` module is used — no third-party packages.

## Consequences

All modules call `configure_logging()` at startup (or import the pre-configured logger). Direct `print()` statements for application events are replaced with logger calls.
